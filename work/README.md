# work/ — one directory (or file) per unit of work

Each unit gets `U###-<slug>/` containing at least a `UNIT.md` (start from
`../work/UNIT-TEMPLATE.md`) plus whatever evidence files the work produces. Small units may
be a single `U###-<slug>.md` file instead — judgment call; the record's readability is what
matters.

Rules:

- Open the unit file and its `LEDGER.md` row (`planned`) **before** starting the work.
- Log as you go, not retrospectively.
- Close with an honest status. `refuted`, `blocked`, and `abandoned` are first-class
  outcomes — never dress them up as done.
- A unit's record must let a reader verify the outcome without redoing the work.
